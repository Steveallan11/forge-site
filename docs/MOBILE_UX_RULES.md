# Forge Mobile UX Rules

Mobile must be designed independently.

## Core rule
**ONE IDEA PER VIEWPORT.**

Desktop can be exploratory.
Mobile should be directed and cinematic.

## Do
- Use portrait-specific crops
- Use sequential notifications
- Reduce hero headline size so the full thought remains understandable
- Keep the mobile header compact
- Use one dominant CTA
- Use a compact persistent Job 02841 state
- Present survey, report and quote sequentially
- Present AI Office one command/result at a time
- Make Blueprint one question per screen
- Keep contrast high enough for use outdoors / in vans / on site
- Respect reduced-motion preferences

## Do not
- Use mystery + hotspots
- Leave large dead vertical gaps
- shrink desktop diagrams until unreadable
- force two large CTAs side-by-side
- stack every desktop card into a giant scroll
- use hover-dependent interactions
- scroll-jack the whole site
