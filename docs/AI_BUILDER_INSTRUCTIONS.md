# AI Builder Execution Instructions

Treat the approved docs in /docs as authoritative.

Do not invent a new brand, colour system, category or marketing structure.

## Build goal
Create a cold-market sales experience that feels like:
- an interactive short film
- a real trade business
- a live operating system

The website should move through:
**CHAOS → CONTEXT → CONTROL**

## Priority
1. Five-second clarity
2. Owner recognition
3. Differentiation
4. Product comprehension
5. Proof
6. Capability escalation
7. Trust / control
8. Conversion
9. Visual novelty

## Anti-template rules
Do not default to:
hero → logo strip → three benefits → feature cards → dashboard → testimonials → pricing → FAQ → CTA.

Avoid:
- bento grids
- purple gradients
- glowing AI orbs
- stock office imagery
- fake testimonials
- invented metrics
- generic integration diagrams
- repeated browser mockups
- meaningless animation

## Production discipline
- Reuse the real Forge/source-system architecture where appropriate.
- Never expose source-company branding or private data.
- Use approved demo data consistently.
- Use the locked Forge palette.
- Use the real product to prove claims whenever possible.
- Keep pricing at £399/month and implementation from £995 unless explicitly changed.
- Build the Blueprint as a mini-product, not a lead form.

## Final test
A cold trade-business owner should reasonably say:
**Hold on. It does all of that? What would this look like in my business?**
