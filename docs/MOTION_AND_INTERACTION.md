# Motion & Interaction

## Principle
Movement must explain business cause → effect.

Approved examples:
- message → enquiry
- enquiry → customer / property / job
- survey → findings
- approved findings → report
- report → quote
- accepted quote → job
- job complete → invoice
- invoice → paid
- AI command → real records filter / update

## Signature interactions
1. Desk exploration — desktop only, directed sequence on mobile
2. Persistent Job 02841 story
3. Survey → findings → report → quote
4. Attention engine collapse
5. AI Office controlling real UI
6. Blueprint assembling live

## Motion style
Use restrained easing, opacity, transforms and subtle depth.

Avoid bounce, constant floating, excessive parallax, decorative particles, random glows and animations with no business meaning.
