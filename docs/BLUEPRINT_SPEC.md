# Forge Blueprint Spec

## Purpose
The Blueprint is the primary conversion mechanism. It must provide value before requesting contact information.

## Questions
### 1. What trade are you in?
Roofing / Building / Electrical / Plumbing / Maintenance / Other

### 2. How many people need to know what's going on?
1–5 / 6–10 / 11–25 / 26+

### 3. What currently holds things together?
WhatsApp / Email / Xero / Spreadsheets / Calendar / CRM / Job software / Mostly me / Other

### 4. Where does it hurt most?
Enquiries / Quotes / Surveys / Paperwork / Jobs & team / Customer updates / Invoicing / Finding information / Follow-ups / Everything comes through me

## Live assembly
The visual Blueprint should build as answers are selected:
- Trade changes workflow
- Team size introduces relevant roles
- Existing tools connect to the operating flow
- Main pain highlights the area Forge would tackle first

## Output
Before asking for contact details show:
1. **YOUR FIRST FORGE**
2. A tailored visual flow
3. Relevant modules
4. Existing systems that can stay
5. Three grounded priorities
6. Human approval / automation points

Then ask:
**Want us to map the real version with you?**

Fields:
Name / Company / Email / Phone optional

CTA:
**TALK THROUGH MY BLUEPRINT**
